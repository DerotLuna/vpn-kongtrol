Policy Quick Reference

How to configure routing policies

Edit ~/.kongtrol/kongtrol.yaml → section policies:

Domains

claude.aiExact domain only
*.anthropic.comAll subdomains (not root)

IPs & Ranges

172.28.152.26Single IP (auto /32)
10.0.0.0/24256 IPs — 10.0.0.*
10.0.0.0/1665,536 IPs — 10.0.*.*
10.0.0.0/816M IPs — 10.*.*.*

Higher /number = fewer IPs (more specific). Just an IP without / = single host.

Example

policies:
  - name: Office
    match:
      ip_ranges:
        - 10.10.0.0/16
        - 172.28.152.26
      domains:
        - "*.company.com"
    via: office
