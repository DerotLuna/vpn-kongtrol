# ADR-0076: Data and privacy wording: where, what leaves, what is deleted

Version 1.0.0 · 2026-11-20

Status: Accepted · Date: 2026-11-20 · Decision-makers: project maintainer (owner)

Refines the wording of [ADR-0034](0034-uninstall-and-update-notice.md) (stays
accepted; no behaviour changes).

## Context and Problem Statement

The owner read `kongtrol uninstall --help`: "Desinstala Kongtrol de este equipo (tus datos se
quedan)". A reader can think the data stays *somewhere else*, for example on a server. Kongtrol is
local only: data lives on this computer and nowhere else. A sweep of the user-facing strings found
the same kind of doubt in other places:

- "tus datos se quedan" / "your data stays" without saying where (uninstall help, plan and final
  line, landing guide, privacy page, README).
- `kongtrol export`: "para compartir con tu equipo" — in Spanish *equipo* is both "team" and
  "computer", and it did not say that Kongtrol sends the template nowhere.
- Dashboard export: "Descarga tu configuración" reads like a download from the internet; it is a
  file saved on this computer.
- Dashboard Privacy card: "no envía nada fuera de este equipo salvo lo que actives aquí", but the
  public IP lookup is turned on in Seguridad, not there.
- Home card, public IP off: "nada sale de tu equipo" — the VPN traffic does leave; what is true is
  that Kongtrol asks no external service.
- "Borrar todos mis datos" listed the keychain passwords but not the audit signing key that is
  also deleted, and did not say that `daemon.log`, `tray.log`, `api-token` and `run/` stay while
  the daemon runs (`internal/uninstall/purge.go` `runtimeFiles`).
- `cli.uninstall.purged` said "%d contraseñas" but counts every keychain entry deleted
  (usernames, passwords and `_system.audit_hmac_key`, `uninstall.Credentials`).
- Wizard: kill switch "bloquea todo el tráfico si cae la VPN" / "nada sale sin cifrar" and DNS
  guard "tu proveedor no ve qué webs abres" promised more than the code does (a split-tunnel kill
  switch blocks only what went through the dropped tunnel, ADR-0058/0063; the DNS guard hides
  name lookups, not the sites' IPs).
- Terms named only the public IP lookup as optional, not the new version notice.

## Decision Drivers

- Owner rule (2026-11-20): nothing may leave doubt about data, security or privacy.
- AGENTS.md "Local only" and "User guidance": short lines, no jargon, say what happens.
- Every claim matches the code: `config.DefaultPaths` (`~/.kongtrol/kongtrol.yaml`),
  `uninstall.Purge` / `Credentials` / `runtimeFiles`, keychain service `vpn-kongtrol`,
  `cmd/kongtrol/cmd_uninstall.go` (`uninstallExtraFiles`: a `--config` file and a custom audit log
  path are deleted too), `cmd/kongtrol/daemon_update.go` (`purgeDataFromDaemon`, `KeepRuntime`).
  Outbound calls: `docs/SECURITY.md` "Network connections Kongtrol makes".

## Considered Options

1. Leave the strings; explain on the privacy page only.
2. **Fix each ambiguous string in place, with the same three answers everywhere.**

## Decision Outcome

Option 2. Every user-facing string about data answers, when it applies:

1. **Where:** "en este equipo" / "on this computer", naming `~/.kongtrol` and the system keychain
   when it helps; "no hay copia en otro lugar" / "there is no copy anywhere else".
2. **What leaves:** only the two opt-in lookups (public IP, new version notice), both off by
   default; never "nothing leaves" when VPN traffic obviously does.
3. **What is deleted and whether it can be undone:** list it (folder, passwords, audit key, what
   stays) and say "no se puede deshacer" / "cannot be undone".

Changed surfaces: `internal/i18n/lifecycle.go` (uninstall help, flags, plan, confirm, result
lines), `internal/i18n/i18n.go` (export help, wizard keychain banner, kill switch and DNS guard
question and hints, audit log hint), `web/ui/src/i18n/pages/settings.ts` (export, Privacy card,
recent connections, delete-my-data dialog), `web/ui/src/i18n/pages/home.ts` (public IP off hint),
landing privacy policy 1.7.0, terms 1.5.1, guide uninstall block, README command table;
`docs/CLI*.md` and `docs/cli.json` regenerated by `make docs`.

### Consequences

- Good: a non-technical reader cannot read "stays" as "stays on a server"; the delete dialogs list
  exactly what goes.
- Neutral: some lines are longer; they stay one idea per line.
- Not done here (files owned by parallel work): `docs/SETUP.md` ("Desinstalar (tus datos se
  quedan)", old kill switch question) and `landing/src/components/sections/Download.tsx`
  ("tus datos se quedan") need the same wording.
