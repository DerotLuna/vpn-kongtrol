# Five consumer VPN app integrations

Access date for the vendor documentation and source below: 2026-11-24. Roadmap priorities are [#52](https://github.com/DerotLuna/vpn-kongtrol/issues/52), [#53](https://github.com/DerotLuna/vpn-kongtrol/issues/53), [#54](https://github.com/DerotLuna/vpn-kongtrol/issues/54), [#55](https://github.com/DerotLuna/vpn-kongtrol/issues/55) and [#58](https://github.com/DerotLuna/vpn-kongtrol/issues/58).

| Provider | Verified interface and lifecycle evidence | Direct path and constraints |
|---|---|---|
| Mullvad | The official CLI documents `connect`, `disconnect`, `status` and relay selection. Linux commonly exposes `wg0-mullvad`. A named service or interface override is needed where the system exposes a generic interface. | Generate a standard WireGuard `.conf` in the account. OpenVPN servers were retired in January 2026. [CLI](https://mullvad.net/en/help/how-use-mullvad-cli), [WireGuard export](https://mullvad.net/en/help/easy-wireguard-mullvad-setup-linux), [OpenVPN retirement](https://mullvad.net/en/blog/final-reminder-for-openvpn-removal) |
| PIA | The current manual lists `piactl` paths for Windows, macOS and Linux and documents connection state, region discovery, selection and disconnect. The Windows source identifies its OpenVPN WinTUN adapter. The reported WireGuard name is `wgpia0`. Use a provider service or set the interface explicitly for generic `tun` and `utun` names. | Download OpenVPN from the Client Control Panel. Use PIA service credentials and keep them in the OS keychain. Kongtrol does not automate account login or change PIA background settings. [CLI](https://helpdesk.privateinternetaccess.com/hc/en-us/articles/46815372532123-PIA-Desktop-Command-Line-Interface), [Windows source](https://github.com/pia-foss/desktop/blob/master/daemon/src/win/win_wintun.cpp), [WireGuard adapter report](https://github.com/pia-foss/desktop/issues/96), [OpenVPN export](https://helpdesk.privateinternetaccess.com/hc/en-us/articles/46701665830811-Where-Can-I-Find-Your-OpenVPN-ovpn-Files) |
| ExpressVPN | Linux and macOS document `expressvpnctl` with the app running or background mode enabled. Windows asks for elevated control and the CLI requires app 12.69.0 or newer. Windows manual attach uses a VPN interface. Lightway Turbo transparently filters traffic without exposing one. The vendor documents disabling Turbo to expose a TUN interface. A CLI status of connected cannot supply an interface for routing. | Download OpenVPN and its separate manual credentials from the provider account. [Linux CLI](https://www.expressvpn.com/support/vpn-setup/app-for-linux-cli/), [macOS CLI](https://www.expressvpn.com/support/vpn-setup/app-for-macos-cli/), [Windows CLI](https://www.expressvpn.com/support/vpn-setup/how-to-use-expressvpn-cli-windows/), [Lightway Turbo](https://www.expressvpn.com/support/troubleshooting/network-adapter-not-available-on-windows/), [OpenVPN](https://www.expressvpn.com/support/vpn-setup/manual-config-for-linux-with-openvpn/) |
| Windscribe | The current vendor source documents the desktop and Linux headless `windscribe-cli`, exact locations and `connect` / `disconnect` / `status`. The old v1.4 command has a different name. The Windows vendor repository records `WindscribeWireguard`. Use the override for generic interface names. | The vendor account can generate WireGuard and OpenVPN files depending on access. [CLI](https://github.com/Windscribe/Desktop-App/blob/master/skills/windscribe-cli/SKILL.md), [adapter example](https://github.com/Windscribe/Desktop-App/issues/257), [config generators](https://windscribe.com/features/config-generators) |
| CyberGhost | Windows installs `Dashboard.exe` under CyberGhost 8. macOS uses its own tunnel interface for WireGuard. The Linux CLI docs explicitly require elevated connect/stop. Kongtrol detects Linux installs and can attach once the tunnel is brought up manually and its interface is identified. | Use the vendor OpenVPN manual setup and import referenced CA/cert/key files. [Windows path](https://support.cyberghostvpn.com/hc/en-us/articles/360016440480-How-to-Configure-Windows-Firewall-to-Unblock-CyberGhost), [macOS helper](https://support.cyberghostvpn.com/hc/en-us/articles/360016909820-Why-Does-CyberGhost-VPN-Require-Me-to-Install-a-Helper-Tool-on-Mac), [Linux CLI](https://support.cyberghostvpn.com/hc/en-us/articles/360020835894-CyberGhost-VPN-CLI-App-Linux-FAQ), [manual OpenVPN](https://support.cyberghostvpn.com/hc/en-us/sections/203068369-CyberGhost-VPN-Manual-Setup) |

An upper-case country is normalized for Mullvad. PIA uses a region ID and ExpressVPN uses the displayed region text. Windscribe receives the requested location as one argument. Without a target the provider keeps its own default. The CLI command plan is separate from tunnel liveness. Kongtrol follows the OS interface and does not attach to bare `tun0`, `utun2` or `wg0` unless the user explicitly selects the interface. Device, service and executable aliases that are not listed by the vendor remain best effort.

Live account authentication, GUI launch, interface aliases across all protocols and desktop versions, and coexistence with other VPN apps: **no verificado**. Repeat the following for each platform and provider with a signed-in account. Confirm detection while disconnected, attach an already-connected tunnel, control through the installed CLI where supported, wait for manual connection with auto disabled, select and change region, disconnect, observe an unexpected drop and repeat with an interface override. Verify that rules, DNS and coexistence apply to the intended interface. Test ExpressVPN on Windows with and without Lightway Turbo and CyberGhost on Linux with a manual tunnel.
