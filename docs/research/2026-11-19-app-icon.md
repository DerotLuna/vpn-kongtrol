# Research: app icon per platform and installer branding

Version 1.0.0 · 2026-11-19

## Question

For ADR-0052: what shape, margin and sizes each platform expects from an app icon; how to embed
it in `kongtrol.exe` without cgo; which images Inno Setup 6 takes for the wizard and at which
sizes; why the update Ready page cut its text.

## Findings

1. **Windows wants size-specific frames.** Windows picks the exact size or the next one above
   and scales down (2). The common taskbar sizes are 24 (100 %), 30 (125 %), 36 (150 %); title
   bar and context menu 16–24. A 16–24 px frame of a plated icon leaves a 10–15 px head: the face
   is lost. Fluent asks for 3:1 against both themes for at least half of the icon (1): an Ink
   plate passes on light only; a mid-tone of relative luminance 0.143–0.30 passes on both white
   and `#202020`; `#857c6b` (≈ 0.20) sits in the middle.
2. **Windows plates.** Fluent icons are drawn on a 48 px grid and use the space (1); exact
   keylines for plated icons are not published, so 44/48 (2 px each side) is a reasoned choice,
   **no verificado** against a Microsoft template.
3. **Apple.** The HIG now asks for square, unmasked artwork that the system masks, and for
   macOS 26 the layered Icon Composer format (3). A classic `.icns` built with `iconutil` keeps
   the Big Sur convention: the artwork carries its own rounded plate inside a transparent
   margin (4). macOS 26 shows icons that do not follow its new format inside a system plate;
   whether that applies to this `.icns` is **no verificado** (no macOS 26 machine here). The
   Icon Composer path needs Xcode's `actool` and an `Assets.car`; left for later.
4. **iOS touch icon.** Square, no transparency, the system rounds it (3): full-bleed plate.
5. **Inno Setup 6.6+.** PNG works for both wizard images, one file per DPI area avoids blur
   (5, 6). The welcome page is off by default (7), so the side image appears on the finished page.
   Text in an image cannot follow `[Languages]`; `[Messages]` can (`es.` / `en.` prefixes).
6. **The cut-off Ready text.** Inno sizes `ReadyLabel` for its own message; a caption set from
   `[Code]` keeps the old height. `AdjustLabelHeight` grows it and returns the difference;
   `IncTopDecHeight` moves the memo below by that much (8). Reproduced with the CI's Inno 6.7.4:
   before, one line ending "…solas al terminar. El"; after, both lines.
7. **Embedding in `kongtrol.exe`.** `rsrc` is pure Go and already pinned; the `.syso` is linked
   only for its `GOOS_GOARCH` suffix, so Linux/macOS cross builds ignore it (9). Version info
   would need `go-winres` (10) and a second tool; not done.

## Recommendation

Adopted in ADR-0052: Ink plate + Bone solid mark, plain mid-tone mark up to 24 px; per-platform
geometry; `rsrc` for both binaries; Inno images per DPI area, tagline as translated text;
`FitLabel` for replaced captions.
