# VPN profile vocabulary

Accessed 2026-11-26.

- [OpenVPN: connection profiles](https://openvpn.net/as-docs/v3/connection-profiles/)
  describes profiles as configuration for a connection and supports multiple
  profiles per user.
- [Microsoft: VPN overview](https://learn.microsoft.com/en-us/windows/security/operating-system-security/network-security/vpn/vpn-guide)
  uses VPN profiles for configurations with different protocols and settings.
- [GOV.UK: create accounts](https://design-system.service.gov.uk/patterns/create-accounts/)
  recommends clear, consistent labels for the same action.

These sources support "VPN profile" as a recognizable name, not a proof that
it is optimal for every user. Kongtrol's profile is broader than an OpenVPN
file: it can attach to a provider app. A file's protocol is not evidence of
its provider; Kongtrol only recognizes some providers.
