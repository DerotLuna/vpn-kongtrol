# Dashboard search and cards

Accessed 2026-11-25.

- [W3C combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/): keyboard navigation and a named input for filtered results.
- [React Aria Autocomplete](https://react-spectrum.adobe.com/react-aria/Autocomplete.html): filtering and keyboard navigation for a listbox.
- [MDN multicolumn breaks](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Multicol_layout/Handling_content_breaks): `break-inside: avoid` keeps a card together while columns reflow.

The line-art logo at 48 px and the layout at small widths have not been verified visually on a real display.
