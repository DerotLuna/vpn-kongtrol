# Oracle and Java suggestions

Accessed 2026-11-26.

- [Oracle Java downloads](https://www.oracle.com/java/technologies/downloads/)
  identifies `www.oracle.com` for the download page and `download.oracle.com`
  for Oracle JDK downloads.
- [Java downloads for end users](https://www.java.com/en/download/) uses
  `www.java.com` and links to `javadl.oracle.com` for Java downloads.
- [Oracle OpenJDK builds](https://jdk.java.net/) identifies `jdk.java.net`;
  the page returned 403 from this environment, so its contents were checked
  through the search index. OpenJDK builds are also served by `download.java.net`.
- [Oracle Java download restrictions](https://www.java.com/en/download/help/error_embargoed.html)
  describes export and Oracle policy restrictions. It does not establish
  whether access is currently restricted in Venezuela or on a particular network.

The suggestion contains these hostnames and editable one-level wildcards for
the Oracle and Java websites. It does not cover every login, CDN, app or
subdomain, and neither checks availability nor guarantees access.
